# Security

Lattice Equities is unaudited and runs on devnet only. Don't use it with real
funds.

If you find a vulnerability, email 4yoshiss@gmail.com with the details and steps
to reproduce. Please don't open a public issue for it.

In scope: the Anchor program in `programs/lattice_equities`, the circuits in
`encrypted-ixs`, and the order relay in `relay/`.
